# GitHub Copilot adapter

Copy [copilot-instructions.example.md](copilot-instructions.example.md) to `.github/copilot-instructions.md` in the target repository. Ensure the canonical playbook files referenced in it are also available, or adapt the instructions to the target repository.

Use an explicit task prompt from the [catalog](../../prompts/README.md) in chat. Repository instructions are not a substitute for CI or branch protections.
