# AI Coding Playbook

Portable, engineering-first prompts and execution contracts for interactive AI coding and autonomous engineering workflows.

## About

A tool-neutral toolkit for scoped AI-assisted development, structured tasks, independent verification, and human-reviewed delivery. It supports Codex, Claude Code, Cursor, GitHub Copilot, and Gemini CLI through documented assistant entrypoints.
