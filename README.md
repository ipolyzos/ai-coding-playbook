# AI Coding Playbook

An **experimental personal side project** exploring how AI coding agents can improve everyday software engineering work. The prompts, workflows, and tools here are learning experiments—not production-ready guarantees.

## About

A tool-neutral experimental toolkit for scoped AI-assisted development, structured tasks, independent verification, and human-reviewed delivery. It supports Codex, Claude Code, Cursor, GitHub Copilot, and Gemini CLI through documented assistant entrypoints.
