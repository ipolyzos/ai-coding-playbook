# Execution plan

## Objective
Convert an approved task contract into bounded, verifiable increments.

## Workflow
1. Confirm allowed paths, forbidden actions, and acceptance criteria.
2. Identify dependencies, rollback options, and required approvals.
3. For each increment specify edits, checks, and stop conditions.
4. Stop if scope or essential requirements are ambiguous; obtain approval before changing scope.

## Required output
Report evidence, unresolved questions, checks performed, and any approval required before proceeding.
