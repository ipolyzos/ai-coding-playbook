# Independent self-review

## Objective
Review the final diff against the task contract and repository conventions.

## Workflow
1. Inspect all changed files and relevant surrounding behavior.
2. Check correctness, security, compatibility, test gaps, and unnecessary edits.
3. Classify findings by severity and cite concrete locations.
4. Fix only within authorized scope; report unresolved findings without claiming independent human approval.

## Required output
Report evidence, unresolved questions, checks performed, and any approval required before proceeding.
