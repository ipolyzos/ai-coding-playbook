# Repository discovery

## Objective
Inspect repository structure, architecture, tests, and policies without making changes.

## Workflow
1. Locate instructions, build manifests, CI definitions, and ownership boundaries.
2. Map relevant modules and execution paths with file references.
3. Record baseline commands, available tools, and unknowns.
4. Produce a concise evidence-based repository map; never infer permissions from available tooling.

## Required output
Report evidence, unresolved questions, checks performed, and any approval required before proceeding.
