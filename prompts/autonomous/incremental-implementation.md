# Incremental implementation

## Objective
Execute one approved increment at a time.

## Workflow
1. Confirm branch and current baseline before editing.
2. Make minimal cohesive changes and add focused regression tests.
3. Run relevant checks and record command results after each increment.
4. Do not commit unrelated changes; stop on blocked validation or authorization boundaries.

## Required output
Report evidence, unresolved questions, checks performed, and any approval required before proceeding.
