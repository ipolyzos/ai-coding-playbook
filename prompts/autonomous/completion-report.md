# Completion report

## Objective
Produce an auditable summary without unsupported success claims.

## Workflow
1. List changes and map each acceptance criterion to evidence.
2. Report executed checks with commands and passed, failed, blocked, or not-run outcomes.
3. Identify outstanding risks, approvals, and follow-up work.
4. Distinguish implementation complete from merged, deployed, or production-ready.

## Required output
Report evidence, unresolved questions, checks performed, and any approval required before proceeding.
