# Autonomous task intake

Read the task contract before making changes.

1. Validate objective, acceptance criteria, allowed paths, forbidden actions, and available tools.
2. Discover repository instructions, architecture, and baseline test commands.
3. Identify ambiguities, dependencies, and high-risk actions.
4. Produce a bounded plan with independently verifiable increments.
5. Request approval before expanding scope, publishing, merging, deploying, or destructive changes unless explicitly pre-authorized.

If essential requirements are missing, stop and ask. Never silently infer authority from tool availability.
