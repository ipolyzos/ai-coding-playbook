# Scope control

## Objective
Keep autonomous work within explicitly authorized boundaries.

## Workflow
1. Read the task contract before any edit or external action.
2. Check each proposed file or action against allowed paths and forbidden actions.
3. Stop and request approval for scope expansion, destructive operations, merges, or deployments.
4. Do not treat a successful tool call as authorization.

## Required output
Report evidence, unresolved questions, checks performed, and any approval required before proceeding.
