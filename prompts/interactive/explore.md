# Explore a codebase

## Inputs
- Question: [what needs understanding]
- Starting points: [paths, symbols, interfaces]
- Depth: [overview or detailed trace]

## Workflow
1. Inspect repository documentation, entry points, and build files.
2. Trace relevant execution paths and dependencies; distinguish observed facts from assumptions.
3. Identify architectural boundaries, data flow, and key tests.
4. Cite file paths and symbols for substantive findings.
5. Summarize the answer, unknowns, and focused next inspection steps.

Do not modify files unless separately authorized.
