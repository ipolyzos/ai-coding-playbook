# Plan a bounded change

## Inputs
- Objective: [outcome]
- Constraints: [scope, compatibility, deadline]
- Acceptance criteria: [observable checks]

## Workflow
1. Inspect relevant repository conventions and current behavior.
2. Identify dependencies and potential breaking changes.
3. Divide work into small independently verifiable increments.
4. For each increment, specify affected areas, tests, and completion evidence.
5. Identify approval gates and unresolved questions before implementation.

Produce an ordered checklist; do not begin modifying code unless requested.
