# Implement a feature

## Inputs
- Objective: [measurable outcome]
- Relevant context: [modules, interfaces, links]
- Allowed scope: [files or subsystems]
- Non-goals: [explicit exclusions]
- Acceptance criteria: [observable behavior]

## Workflow
1. Inspect existing conventions and tests; state any missing context.
2. Propose a small implementation plan, identifying compatibility risks.
3. Implement only approved scope with focused tests.
4. Run relevant checks and capture exact commands and outcomes.
5. Summarize changed files, evidence, residual risks, and unverified items.

Never describe an unexecuted check as passing.
