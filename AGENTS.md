# Agent instructions

This repository is a portable library of engineering workflows, not an executable autonomous agent. Start with [README.md](README.md), then select one task-specific prompt. Keep changes minimal and tool-neutral.

- Create feature branches from `main`; use pull requests and wait for required checks before merging.
- Do not claim tests ran unless their actual results are available.
- Never expose credentials, alter permissions, deploy, or perform destructive operations without explicit authorization.
- Keep interactive prompts, autonomous workflows, and contracts separate.
- Add examples and validation for each new template.
- Avoid duplicating shared instructions in task templates.
